# 星火：渡

以中国工农红军长征为背景的第一人称射击小游戏原型，含两个关卡：
**血战湘江 · 掩护主力过江** 与 **四渡赤水 · 机动游击**。

- 引擎：团结引擎（Tuanjie）2022.3.61t15
- 平台：Windows x64
- 除旗面素材（`Resources/RedArmyFlag.png`）外，场景、美术、音效均在运行时程序化生成

## 运行

构建产物：

```
Build\Starfire.exe
```

双击运行即可。标题界面用 `A` / `D` 选择关卡，按 `Enter` 开始。

命令行参数（调试用）：

```
Starfire.exe -level1            第一关开局
Starfire.exe -level2            第二关开局
Starfire.exe -autostart         跳过标题直接开始
Starfire.exe -autoquit          冒烟测试用，自动退出并打印日志
```

## 背景

### 一 · 血战湘江

1934 年 11 月底，中央红军在湘江边陷入重围。界首渡口是主力西渡的最后通道，
浮桥一旦失守，数万人的队伍就会被截断在江东。湘江战役是长征途中最惨烈的一战，
红军由八万余人锐减至三万余人，却保住了革命的火种。

玩家是红三军团的一名普通战士，弹药只有二十发。能依靠的，是手里的汉阳造、
背后的大刀，和身边的战友。你要顶住追兵，让主力一批批渡过江去——桥在，人就还有活路。
主力过江后炸毁浮桥，切断追兵。

### 二 · 四渡赤水

1935 年初，红军在川黔滇边被数十万敌军围追堵截。赤水河两岸山高谷深，
渡口、踏脚石与溜索是唯一的通路。玩家要利用地形与敌周旋，
在三个渡口之间机动转移，抵达对岸信标。

## 关卡流程

**第一关 · 血战湘江**

1. **标题**：选择关卡。
2. **掩护渡江**：主力队伍从对岸沿浮桥左侧一批批走过（共 6 批），
   敌军从右岸桥面与江岸分批进攻。HUD 目标显示「已过 N/6 批」。
3. **断后炸桥**：主力过江后，前往桥头长按 G 引爆炸药。
   起爆前桥上残敌会掉头往对岸跑，炸药一响，连人带碎木一起按抛物线掀进江里。
4. **胜利 / 阵亡**：结算歼敌数，按 Enter 重开。结算演出切成白天，
   风雪停歇、天色放晴。主角端着枪走到阵前，收枪后右手敬礼——
   步枪斜挎到背后：枪托落在右胯、枪口从左肩后探出来，胸前的挎带绕到左肩，
   不再是悬在身体一侧。

**第二关 · 四渡赤水**

1. 夜里从赤水河东岸出发，队里有人举火把照明；沿河谷机动，
   跨越踏脚石与绳桥抵达各渡口。
2. 三个渡口各有一名敌军哨兵，全部清除后对岸信标亮起。
3. 抵达信标即为胜利；阵亡则显示「倒在赤水河畔」。

## 核心系统

- **汉阳造**：弹匣 30 发，开局备弹 **20 发**，补给极少——主要靠从阵亡敌军身上搜刮
  （每具尸体 2–4 发，20% 概率掉落手榴弹）。每射一发强制拉栓 1.5 秒，
  第一人称能看到枪身下沉、枪机后拉再推回，装填时整支枪放低；
  拉栓时右手离开枪颈、翻上去攥住拉柄球头，四指弯成圈兜住球头、拇指从上面别住，
  跟着拉柄抬起、后拉、推回，闭锁后才回到握把，手和球头之间不会开缝；
  拉栓声是**远距离收音**的闷响：老枪金属磨损，机件摩擦发涩不发脆，
  带着山野背景里一层很轻的风声，没有"叮"的清脆感；
  开火瞬间枪身后退上跳、镜头被顶起后回落，一发一发都有分量；
  命中头部 100、躯干 40、四肢 20。开火有程序化枪口星芒火光与带山谷回声的枪声：
  高频毛刺被压掉，只剩一记低频闷响加短促的"啪"，山里传回来的尾巴更沉；
  夜里能照亮双手和身前的地面；敌我双方的枪口都会闪光。
- **持枪视角**：第一人称枪模由程序化双手持握——右手扣扳机、左手托护木，
  小臂从画面下缘伸入。枪模自带一盏短程补光，站在阴影里、背对太阳或在夜里，
  枪和手也不会糊成一团黑。**待机时枪身随呼吸缓慢起伏、枪口有极轻微的漂移**；
  走路时枪随脚步左右轻摆，奔跑时枪口朝下收到身前、摆动幅度收住；
  枪还压着时扣扳机打不响；松开 Shift 或按住右键瞄准，枪会平滑举起，
  入瞄后收起枪托，但双手一直握着枪——两只手掌扣在枪颈和护木上，
  小臂绕腕子往画面下方转出去，不挡照门与准星。
- **体力**：满体力可连续奔跑约 5.5 秒，耗尽后必须停下喘气（0.8 秒后开始恢复，
  恢复到 25% 才能再次奔跑）。体力越低，画面晃动与喘息越明显，HUD 左下角显示体力条。
- **机瞄**：步枪装备时按住鼠标右键，视野从 64° 收到 40°，散布压到 6%，
  移速与视角灵敏度降低。照门两肩与准星尖各点一颗旧铜色小珠，形成三点一线，
  举枪后三点正好压住画面中心，暗处或逆光也能看出枪口指向。
  机匣、枪机套筒与表尺做成独立零件，举枪后仍能看清拉机柄与照门的层次。
- **冲锋号**：每关都有一名号兵（第一关是队尾第五人，第二关是第三名战友）。
  号兵不参战，跟着队伍行进；开局 90 秒时停下吹号，全场友军振奋 15 秒：
  **移动速度 +20%、AI 战友散布减半（命中率翻倍）、主角每次击杀回复 5 点生命**。
  号声是程序化合成的四音上行铜管，带起音滑音与气声，结束后自动归位继续行军。
- **驳壳枪（C96）**：副武器，弹匣 **6 发**，开局带 **4 个备用弹夹（24 发）**。
  打空自动换弹，也可随时按 `R`；换弹 1.35 秒，枪身往右下沉、弹仓向前下方脱出，
  完成后枪归位。按住右键机瞄：视野收到 50°，散布压到 16%，
  照门缺口、准星珠与画面中心三点一线。弹夹靠缴获——
  每名敌军阵亡必掉一个手枪弹夹（6 发），备弹上限 8 个弹夹。
  枪身按 C96 做成独立零件：机匣、表尺、铣削槽、枪机、击锤环、扳机护圈与十发桥夹仓，
  第二关持火把的战友也配这把枪。
- **大刀**：滚轮或按 3 切换，无需弹药，持刀移速 ×1.15。
  左键轻击（前摇 0.42 秒、伤害 34、范围 2.35 米），右键重击（前摇 1.15 秒、伤害 92、范围 2.9 米），
  挥砍动作、刀风与金属撞击声都做了轻重两套。
  刀模按红军大刀做成黑色宽刃、斜刀尖、环形刀首、缠绳刀柄，右手握住刀柄压在画面右下角。
  刀是单边开刃：左侧一条磨亮的刃口，右侧加厚的刀背，刀尖从刃口斜收向刀背，
  不是两边对称、像剑一样的尖头；战友与敌军近战用的大刀也是同一副刀型。
- **背刺处决**：站在敌人正背后 2.5 米内按右键，镜头压下去、刀从后腰捅入再拧一下，
  处决全程玩家无敌、目标必死，音效与动作参考《艾尔登法环》的背刺。
  找不到可处决目标时右键自动退回重击。
- **信仰**：击杀敌人或靠近火堆积攒；满 100 后按 F，5 秒内移速 ×1.5、拉栓速度 ×1.8，
  并且**无视体力消耗**——力竭状态下也能继续冲刺。
- **爆头判定**：敌人带有放大的隐形爆头盒，覆盖头部与肩颈，
  擦到上胸也会判为爆头；子弹使用小半径球形判定，不再要求像素级对准。
- **姿态**：C 蹲下（移速 ×0.55、眼高降低），Z 趴下（移速 ×0.28、眼高更低）。
  Space 跳跃，蹲姿起跳会先站起；趴下时按 C 先回到蹲姿；奔跑仅在站姿可用。
  第三人称下蹲着不动时是**单膝跪姿**：前腿膝盖抬起、小腿竖直踩实，后腿膝盖着地，
  上身直立微侧；一迈步就平滑过渡回低姿蹚步。
- **卧倒动作**：按 Z 不是瞬间贴地，而是走一整条动作链——
  **站立 → 屈膝下沉 → 单膝触地（前腿踏出撑住）→ 俯身前探、双小臂落地 →
  后腿放平 → 俯卧定型**，起立时反放一遍。每个关节（髋、膝、踝、肩、肘、头）
  都按关键帧插值，脚掌始终压平不穿地。
  定型后的俯卧姿势是：**双小臂着地撑住上身，汉阳造横架在两条小臂上，
  枪管水平指向前方，抬头上望，髋与双腿平贴地面**；
  手背和小臂离地留出余量，不会陷进地面里。
- **探头**：按住 Q / E 让镜头横向探出并轻微侧倾，可以躲在沙袋后露头射击；
  侧向遇到障碍会自动收紧，卧姿不可探头。
- **低温与受击**：湘江水面为寒冷区，体温持续下降；低于 50 出现冰冻特效，
  低于 0 开始减速。受伤时屏幕边缘泛红、镜头抖动；血量低于 30% 画面转灰暗，
  低血量时右下角残留血迹，提醒你该找火堆了。
- **暴风雪**：全图（含敌方）都在风雪里，能见度、听觉范围与体温一起下降；
  雪片随风向横扫，敌我动作在雪幕里都会变慢、变沉。
- **战场纵深**：第一关桥头增加多层沙袋路障与出生点后的沙包掩体；
  战场向后方扩出一段纵深，敌军过桥后也留得出退路，不会再被逼到地图边缘。
- **桥面工事**：第一关浮桥中段改成 4 组沙袋横墙（相距 6 米、左右错开，
  每组 3×3 袋、顶层留射击孔），旁边配弹药箱、板车、散落木板与踩破的沙袋。
  桥面不再是光板通道，而是可以来回争夺的第一战场。
- **河滩游击工事**：第二关两岸河滩、平地和镇口补了 23 道沙袋矮墙与 11 栋吊脚楼，
  墙与墙之间留出击路线，可以借矮墙探头压制、再退到楼后换位。
- **血雾与血珠**：中弹不再留下悬空的血块，而是沿弹着面法线喷出一蓬血雾；
  血珠受重力下坠，碰到地面、沙袋或桥板立即消失，尸体下只在地面铺一层薄血泊。
- **人物细节**：军装、绑腿、草鞋、子弹带、挎包、搪瓷缸都拆成独立零件；
  每名战士随机长出胡子、胡茬或脸颊伤疤，裤腿带补丁，子弹带与胸带交叉成 X。
- **火堆**：同时恢复体温、生命与信仰，是唯一的补给点。
- **河水**：流速再降 40%，三层波形叠加、近岸逐渐衰减，水面起伏更缓更自然；
  飞溅粒子的纵向速度压到接近水面，不会再穿过第一关的浮桥桥面；水声音量降到 0.175。
- **第三人称**：按 V 在第一 / 第三人称间切换。第三人称下身体显形，
  走、跑、蹲、趴都按关节摆姿势，腿有步幅、手臂反向摆、身体随步伐上下起伏；
  速度直接读实际水平速度，撞墙停住时腿也会停。
  镜头有三档距离，按 **T** 在近（2.4 米）/ 中（3.6 米）/ 远（5.0 米）之间循环，
  换档时平滑推拉而不是瞬移；碰到墙壁、战壕壁或桥栏会自动收进来。
- **第三人称持械与切枪**：身体右手上挂着汉阳造、驳壳枪、大刀三种武器模型，
  站着时双手端枪、姿态随实际武器变化；步枪端在手上时背后的枪就收起来，
  换成驳壳枪或大刀时步枪会重新挎回后背。
  按 1 / 2 / 3 或滚轮切枪时有一段 **0.45 秒的换装动作**：上半身微微下沉、
  侧身让对方看不见的空档，到一半时旧枪放下、新枪举起，大刀还会甩一行腕花；
  换装过程中手臂摆动幅度收住，枪不会乱甩。趴下时汉阳造仍在右手里压在小臂上。
- **火把**：主角的特殊装备，不占武器槽。不用时别在左腰上，按 **Tab** 抽出来举在左手，
  再按 Tab 收回去；抽出与收回都是一段 0.35 秒的抬手动作，不是啪地切换。
  举着火把走路时它跟着步幅轻晃，火苗随噪声忽大忽小，自带一盏点光源照亮身前，
  并有一层松脂哔剥的燃烧声贴着耳朵。左手抓在木柄的 **3/5 处**，柄尾从拳头下缘
  伸出来一截，不是攥着火把末端；举火把时步枪只剩右手握着，
  枪身会往右让开一点，不会和火把叠在一起。
- **不落水**：赤水河里敌军和战友都不会下水。敌军被岸线上的硬约束挡在干岸上，
  只在渡口桥面时才过河；战友踩到近岸没入水下的斜坡会被推回岸上。
  万一整个人（脚底沉到水面以下 0.9 米）掉进河里，会被直接送回出发的岸边 / 最近的落脚点，
  不会贴着河床走。
- **击杀信息**：屏幕右上角每出一杀刷一行「名字 · 枪的剪影 · 名字」，
  中间的步枪 / 驳壳枪 / 大刀图标由 IMGUI 直接画矩形拼成，不依赖贴图；
  爆头在行尾加一枚红色「爆头」，战友阵亡也走同一条信息流。
- **暂停菜单**：战斗中按 ESC 暂停（时间停止、画面虚化），左侧 1/4 屏弹出菜单，
  显示战役、战功、歼敌、爆头与用时，提供「继续战斗 / 重新开始 / 选择战役 / 退出游戏」；
  再按 ESC 或点「继续战斗」回到游戏。
- **炮火**：第一关敌军每隔一段时间进行炮击，落点有烟尘与呼啸声，
  爆炸会附带镜头震动与范围伤害——不要站在开阔地。
- **画面**：程序化天空盒、双重方向光、4x MSAA、高质量软阴影、雾效与飘雪；
  起伏地形（近岸缓坡 + 丘陵噪声 + 远处山脊）、河水流动条纹与飞溅粒子、
  地面草皮斑驳贴图、木桥、沙袋、石墙、积雪与冰面均为运行时生成；
  第一关旗杆上的军旗使用 `Resources/RedArmyFlag.png` 旗面素材。

## 敌军 AI

敌军不再是直线冲脸的木桩：

- **三个派系**：中央军（土黄军装、钢盔或军官大檐帽，皮弹匣包与望远镜）、
  川军（土褐布军服、白布包头、腰里别着大烟枪）、黔军（深灰长衫、瓜皮帽、绑腿）。
  生命值分别为 145 / 95 / 75，外观与打起来的"肉度"都能一眼分辨。
- **主动索敌**：优先追击视野内的玩家，被队友吸引时也有惩罚值避免全体跑偏；
  丢失视线后会前往最后已知位置搜索。
- **找掩体**：朝玩家方向在 2.0 / 3.3 / 4.6 米三档半径、±80° 内采样可用掩体点，
  找不到才继续前压。
- **蹲、趴、探头**：进掩体后按掩体高度选择蹲下或趴下；定期从掩体侧向探头开火，
  探头时命中率更高、也更危险。玩家用准星瞄住他时，他会更早缩回掩体。
- **移动节奏**：距离越远移动越快（1.5 倍），接近后减速并横向绕行；
  移动时身体、髋、肩有摆动，被击中会踉跄。
- **奔跑动作**：快速推进时腿摆幅加大、身体前倾、手臂大幅摆动，步频随速度提升；
  慢走与奔跑之间平滑过渡。
- **保持间距**：同队敌人互相推开，始终留出约 1.7 米空当，
  不会叠在同一个掩体后面挤成一团。
- **近身拼刀**：距目标 4.3 米以内自动收枪、亮出大刀；贴身阶段移速提近一倍，
  还不断左右绕步，比端枪时灵活得多，正面硬砍反而容易被绕到侧后。
- **数量**：第一关桥上同时最多 8 名敌军，且生成间隔越来越短；
  第二关每个渡口 5 名守军，被追时还会不断增援。
- **卡住自检**：想走却一秒挪不出半米，就朝侧后方横跨一步再试，连续卡住会换边绕；
  被同伴挤进沙袋堆、木箱里推不出来时，会就近找一块站得下人的空地挪出去，
  不会有人贴着栏杆原地打转。队友同样适用。
- **过桥**：第二关玩家在河对岸时，太平渡守军会沿东岸跑到桥头，
  对齐桥心后踩着木板走过索桥，而不是隔着栏杆挤在岸边；
  无法过桥的距离上则留在岸上据守射击。索桥加宽到 4 米，每个人按自己的车位错开，
  前面半步内有人就站住排队等，桥上不会触发绕路——
  不会再出现几十号人挤在桥口互相顶住、谁也上不去。
- **贴地**：干地上按地形（含娄山关石阶）的高度走，桥面上直接锁在桥板高度；
  生成点不再向下打射线，踩到松树冠、竹竿顶时会把人生拉回地面，
  第二关不会再有守军站在半空。

## 战友 AI

- 守在沙袋后自主索敌、射击、换弹，中弹会蹲低、被压制会转移位置。
- 交火时不会挤成一团：彼此保持约 1.15 米间距，也会主动给玩家让开 2.4 米，
  不会挡在枪口正前方。
- 距离敌人 4.3 米以内同样会切刀对拼，和敌军的大刀有来有回。
- 第二关夜间行军由战友举火把照明（火光会随风闪），持火把的战友改用驳壳枪，
  夜里能照亮身前一段路和敌人的轮廓。
- 第一关队里也有一名火把兵：火把握在手里正握、火头竖直朝上，随步伐轻微摆动。
- 两名号兵（每关一人）随身带着铜号，冲锋号响起时队伍提速、枪法更稳。
