# 星火：渡

以中国工农红军长征为背景的第一人称射击小游戏原型，含两个关卡：
**血战湘江 · 掩护主力过江** 与 **四渡赤水 · 机动游击**。

- 引擎：团结引擎（Tuanjie）2022.3.61t15
- 平台：Windows x64
- 全部场景、美术、音效均在运行时程序化生成，项目不依赖任何外部资源文件

## 运行

构建产物：

```
Build\Starfire.exe
```

双击运行即可。标题界面用 `A` / `D` 选择关卡，按 `Enter` 开始。

命令行参数（调试用）：

```
Starfire.exe -level1            第一关开局
Starfire.exe -level2            第二关开局
Starfire.exe -autostart         跳过标题直接开始
Starfire.exe -autoquit          冒烟测试用，自动退出并打印日志
```

## 背景

### 一 · 血战湘江

1934 年 11 月底，中央红军在湘江边陷入重围。界首渡口是主力西渡的最后通道，
浮桥一旦失守，数万人的队伍就会被截断在江东。湘江战役是长征途中最惨烈的一战，
红军由八万余人锐减至三万余人，却保住了革命的火种。

玩家是红三军团的一名普通战士，弹药只有二十发。能依靠的，是手里的汉阳造、
背后的大刀，和身边的战友。你要顶住追兵，让主力一批批渡过江去——桥在，人就还有活路。
主力过江后炸毁浮桥，切断追兵。

### 二 · 四渡赤水

1935 年初，红军在川黔滇边被数十万敌军围追堵截。赤水河两岸山高谷深，
渡口、踏脚石与溜索是唯一的通路。玩家要利用地形与敌周旋，
在三个渡口之间机动转移，抵达对岸信标。

## 任务指引

- **屏幕指路标**：当前目标始终有一个菱形标记浮在世界里，下面跟着目标名与直线距离
  （如「浮桥桥头 13 米」「渡口 55 米」）。目标在画面外时，屏幕边缘会出现一个指向它的
  箭头，箭头贴在对应的边框上并带内缩标签，跑动中不用回头找路。
- **自动换目标**：第一关进入断后阶段自动指向桥头，炸桥后清除；
  第二关每渡过一条河就切换到下一个渡口，关顶段显示「娄山关关顶」，全部完成后清除。
- **行军地图**：第二关按住 `M` 展开，显示自己（旋转的菱形）、附近战友、已发现敌军、
  虚线行军路线，以及「下一目标 · 直线距离 / 方向角」。

## 主角模型

主角是程序化生成的红军战士，与友军、敌军的几何体美术同一套语言：

- **军帽**：八角帽顶 + 帽檐，正前方是一枚真正的五角星网格（不是贴图，也不是方块旋转）。
- **军装**：灰布军装带门襟、下摆、领口与**红领章**、左右胸袋与袋盖、腰带铜扣、
  腰间弹药袋与挎包；左臂缠**红袖章**。
- **行装**：斜挎胸前背带、双层铺盖卷、背包、水壶。
- **鞋袜**：绑腿（两道布带）+ 草鞋与鞋底。
- **动作**：与蹲 / 趴 / 中弹踉跄共用同一套骨骼层级（髋、脊柱、头、四肢），
  远景第三人称、结算镜头和爆炸演出里也是同一个模型。

## 关卡流程

**第一关 · 血战湘江**

1. **标题**：选择关卡。
2. **掩护渡江**：主力队伍从对岸沿浮桥左侧一批批走过（共 6 批），
   敌军从右岸桥面与江岸分批进攻。HUD 目标显示「已过 N/6 批」。
3. **断后炸桥**：主力过江后，前往桥头长按 G 引爆炸药。
4. **胜利 / 阵亡**：结算歼敌数，按 Enter 重开。

**第二关 · 四渡赤水**

1. 从赤水河东岸出发，沿河谷机动，跨越踏脚石与绳桥抵达各渡口。
2. 三个渡口各有一名敌军哨兵，全部清除后对岸信标亮起。
3. 抵达信标即为胜利；阵亡则显示「倒在赤水河畔」。

## 核心系统

- **汉阳造**：弹匣 30 发，开局备弹 **20 发**，补给极少——主要靠从阵亡敌军身上搜刮
  （每具尸体 2–4 发，20% 概率掉落手榴弹）。每射一发强制拉栓 1.5 秒，
  第一人称能看到枪身下沉、枪机后拉再推回，装填时整支枪放低；
  开火瞬间枪身后退上跳、镜头被顶起后回落，一发一发都有分量；
  命中头部 100、躯干 40、四肢 20。开火有程序化枪口星芒火光与带山谷回声的枪声，
  夜里能照亮双手和身前的地面；敌我双方的枪口都会闪光。
- **持枪视角**：第一人称枪模由程序化双手持握——右手扣扳机、左手托护木，
  小臂从画面下缘伸入。枪模自带一盏短程补光，站在阴影里、背对太阳或在夜里，
  枪和手也不会糊成一团黑。奔跑时枪口朝下收到身前，脚步带动枪身轻晃，
  枪还压着时扣扳机打不响；松开 Shift 或按住右键瞄准，枪会平滑举起，
  入瞄后收起枪托、手腕与双手，只留照门与准星。- **体力**：满体力可连续奔跑约 5.5 秒，耗尽后必须停下喘气（0.8 秒后开始恢复，
  恢复到 25% 才能再次奔跑）。体力越低，画面晃动与喘息越明显，HUD 左下角显示体力条。
- **机瞄**：步枪装备时按住鼠标右键，视野从 64° 收到 40°，散布压到 6%，
  移速与视角灵敏度降低。照门两肩与准星尖各点一颗旧铜色小珠，形成三点一线，
  举枪后三点正好压住画面中心，暗处或逆光也能看出枪口指向。
- **副武器**：滚轮切换大刀，左键轻刀、右键重刀，无需弹药；头部 100、躯干 60、四肢 40。
  手感照 CS2 的小刀做：**左键是横劈**——手腕先往外一翻，刀从一侧由外向内横扫过身前，
  手臂伸到最大幅度后顺着弧线收回，收招快，可以一刀接一刀地连；
  **右键是直刺**——手臂先往后收、刀收到胸前蓄力，再整条手臂直线捅出去，
  刀尖顶到最远点停一下才回抽，前后摇都长、冷却更久。背后贴近敌人时右键改为背刺处决。
  刀身是一整块梯形棱柱：刀背竖直，刃口从刀身中段斜收到平的刀尖，
  顶边齐平，不再是几个方块叠出的、刃口那头缺一角的阶梯刀尖。
  刀模由右手握住刀柄、压在画面右下角，护手与手背都露在视野里。
- **木柄手榴弹**：从阵亡敌军身上缴获，按 `T`（或 `4`）投掷。第一人称是一整套投弹动作：
  右臂从画面右下把弹举到胸前，左手伸过来捏住拉火绳往外一扯，引信头迸出火星和火花、
  拉火绳脱开挂到左手上；随后右臂后摆蓄力、再甩出去，弹脱手飞出，飞行的木柄弹
  引信口一路冒火星与细烟，2.6 秒后爆炸。弹体、地上的掉落物和飞出去的投掷物
  都是同一套木柄手榴弹外形：铸铁弹头、长木柄、加强箍、拉火绳与拉环。
- **爆头判定**：敌人带有放大的隐形爆头盒，覆盖头部与肩颈，
  擦到上胸也会判为爆头；子弹使用小半径球形判定，不再要求像素级对准。
- **姿态**：C 蹲下（移速 ×0.55、眼高降低），Z 趴下（移速 ×0.28、眼高更低）。
  Space 跳跃，蹲姿起跳会先站起；趴下时按 C 先回到蹲姿；奔跑仅在站姿可用。
- **探头**：按住 Q / E 让镜头横向探出并轻微侧倾，可以躲在沙袋后露头射击；
  侧向遇到障碍会自动收紧，卧姿不可探头。
- **低温与受击**：湘江水面为寒冷区，体温持续下降；低于 50 出现冰冻特效，
  低于 0 开始减速。受伤时屏幕边缘泛红、镜头抖动；血量低于 30% 画面转灰暗，
  低血量时右下角残留血迹，提醒你该找火堆了。
- **信仰**：击杀敌人或靠近火堆积攒；满 100 后按 F，5 秒内移速 ×1.5、拉栓速度 ×1.8。
- **火堆**：同时恢复体温、生命与信仰，是唯一的补给点。
- **炮火**：第一关敌军每隔一段时间进行炮击，落点有烟尘与呼啸声，
  爆炸会附带镜头震动与范围伤害——不要站在开阔地。
- **画面**：程序化天空盒、双重方向光、4x MSAA、高质量软阴影、雾效与飘雪；
  起伏地形（近岸缓坡 + 丘陵噪声 + 远处山脊）、河水流动条纹与飞溅粒子、
  地面草皮斑驳贴图、木桥、沙袋、石墙、积雪与冰面均为运行时生成。

## 敌军 AI

敌军不再是直线冲脸的木桩：

- **三个派系**：中央军（土黄军装、钢盔或军官大檐帽，皮弹匣包与望远镜）、
  川军（土褐布军服、白布包头、腰里别着大烟枪）、黔军（深灰长衫、瓜皮帽、绑腿）。
  生命值分别为 145 / 95 / 75，外观与打起来的"肉度"都能一眼分辨。
- **主动索敌**：优先追击视野内的玩家，被队友吸引时也有惩罚值避免全体跑偏；
  丢失视线后会前往最后已知位置搜索。
- **找掩体**：朝玩家方向在 2.0 / 3.3 / 4.6 米三档半径、±80° 内采样可用掩体点，
  找不到才继续前压。
- **蹲、趴、探头**：进掩体后按掩体高度选择蹲下或趴下；定期从掩体侧向探头开火，
  探头时命中率更高、也更危险。玩家用准星瞄住他时，他会更早缩回掩体。
- **移动节奏**：距离越远移动越快（1.5 倍），接近后减速并横向绕行；
  移动时身体、髋、肩有摆动，被击中会踉跄。
- **奔跑动作**：快速推进时腿摆幅加大、身体前倾、手臂大幅摆动，步频随速度提升；
  慢走与奔跑之间平滑过渡。
- **保持间距**：同队敌人互相推开，始终留出约 1.7 米空当，
  不会叠在同一个掩体后面挤成一团。
- **数量**：第一关桥上同时最多 8 名敌军，且生成间隔越来越短；
  第二关每个渡口 5 名守军，被追时还会不断增援。

## 战友 AI

- 守在沙袋后自主索敌、射击、换弹，中弹会蹲低、被压制会转移位置。
- 交火时不会挤成一团：彼此保持约 1.15 米间距，也会主动给玩家让开 2.4 米，
  不会挡在枪口正前方。
- **掩体后的射击节奏**：第一关的战友进掩体后会连续卧倒或蹲下躲子弹，
  每隔一两秒才起身、侧身探出掩体打一枪，打完立刻缩回去；被压制得越久躲得越久，
  起身的时机也越零碎，不会一排人同时冒头当靶子。
- **和主角同一套蹲 / 趴**：战友的蹲下、卧倒不再是自己的一套数值，
  直接读主角的 `StancePose` 关键帧——同样先屈膝下沉、站着不动时单膝跪地，
  卧倒是同样的六帧链条（屈膝下沉 → 单膝触地 → 俯身前探 → 后腿放平 → 标准俯卧），
  小臂也分成两节真的折下去撑住上身，卧倒时步枪从胸前挪到身侧、枪管顺着地面朝前。
- **号兵**：队尾有一名号兵。不打号的时候小号挂在右胯，双手端枪；
  到了吹号的时候先收枪、把步枪斜挎到背后，再把小号从胯上提到嘴边吹响，
  号嘴、号管、加强箍、护环、喇叭口和红缨都在画面里看得见，吹完再把枪取回手里。

## 从源码构建

```
TuanjieEditor\2022.3.61t15\Editor\Tuanjie.exe ^
  -batchmode -nographics -quit -noUpm ^
  -projectPath "E:\study\game\Starfire" ^
  -executeMethod BuildScript.BuildGame ^
  -logFile "E:\study\game\build.log"
```

构建脚本会自动完成：

- 注册 `Enemy` / `Blizzard` / `Campfire` 标签
- 将输入系统切换为旧版 Input Manager
- 将运行时用到的 Shader 加入 Always Included Shaders
- 创建 `Assets/Scenes/Main.unity` 并挂载 `GameBootstrap`
- 输出 `Build/Starfire.exe`
